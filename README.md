# Agentic Commerce Atlas

Live site: https://frbarreto.github.io/agentic-commerce-atlas/

How an AI agent finds a store and pays it: an interactive journey explorer, discovery and payment
maps, 97 players and a benchmark of 29 agentic payment solutions.

This repository only holds the built page (`index.html`, one self-contained file). It is
published from a separate source repository with `npm run deploy`; do not edit it by hand.

Independent research, not affiliated with any company listed. Everything is a desk review of
public sources; no payment solution has been tested hands-on. Logos and names are trademarks
of their owners and appear only to identify them.
